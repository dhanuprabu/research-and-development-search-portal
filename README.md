## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

   # 🔬 Research and Development Search Portal

A web-based Research and Development Search Portal designed to simplify the management of research equipment, laboratory resources, research projects, and academic information. The platform enables users to search, organize, and access research-related resources through a modern and responsive interface.

## ✨ Features

- 🔍 Advanced search functionality
- 🧪 Laboratory and equipment management
- 📂 Research project information
- 👨‍🔬 Researcher resource management
- 📱 Responsive user interface
- ⚡ Fast and user-friendly navigation

## 🚀 Installation

### Prerequisites

- Node.js

### Clone Repository

```bash
git clone https://github.com/dhanuprabu/research-and-development-search-portal.git
```

### Install Dependencies

```bash
npm install
```

### Configure Firebase

Create a `.env.local` file and add your Firebase configuration.

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
```

### Run Project

```bash
npm run dev
```
